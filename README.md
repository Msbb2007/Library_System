<h1>Library Management System</h1>

<p>
  A sophisticated, lightweight library management system designed for efficient administration. This system utilizes a custom JSON-based storage architecture for high performance and easy portability without the need for a heavy database server.
</p>

<h2>Core Features</h2>
<ul>
  <li><strong style="color: #4a90e2;">Admin Dashboard:</strong> Real-time visual overview of library statistics and recent activities.</li>
  <li><strong style="color: #4a90e2;">Book Management:</strong> Full CRUD operations (Add, Edit, Delete) and advanced search capabilities.</li>
  <li><strong style="color: #4a90e2;">User Management:</strong> Advanced control over system users, roles, and granular permissions.</li>
  <li><strong style="color: #4a90e2;">Secure Authentication:</strong> Robust login system for both library members and administrators.</li>
</ul>

<h2>Technical Stack</h2>
<p>
  <strong>Backend:</strong> PHP (Object-Oriented Programming)<br>
  <strong>Storage:</strong> JSON-based File System (Thread-safe operations)<br>
  <strong>Frontend:</strong> HTML5, CSS3 (Modern UI/UX), JavaScript<br>
  <strong>Architecture:</strong> Service-oriented design (e.g., LibraryManager service)
</p>

<h2>Run Project</h2>
<p>
  This project is pre-configured for XAMPP environments. Place the project folder inside the <code style="background: #f4f4f4; padding: 2px 5px;">htdocs</code> directory and access it via:
</p>
<code style="display: block; background: #2d2d2d; color: #f8f8f2; padding: 15px; border-radius: 5px; margin: 10px 0;">
  http://localhost/Library_System/App/
</code>
