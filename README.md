<h1>Library Management System</h1>

<p>
  A comprehensive library management system designed to provide administrators with powerful tools for managing books, users, and system permissions.
</p>

<h2>Core Features</h2>
<ul>
  <li><strong>Admin Dashboard:</strong> Real-time overview of library statistics and recent activities.</li>
  <li><strong>Book Management:</strong> Full CRUD operations (Add, Edit, Delete) and advanced search.</li>
  <li><strong>User Management:</strong> Manage system users, roles, and granular permissions.</li>
  <li><strong>Authentication:</strong> Secure login system for both members and administrators.</li>
</ul>

<h2>Technologies Used</h2>
<p>
  PHP, HTML, CSS, Font Awesome, Vazir Font
</p>

<h2>Run Project</h2>
<p>
  Place the project folder inside the XAMPP <code>htdocs</code> directory and open the following URL in your browser:
</p>
<code>http://localhost/Library_System/App/</code>

<p>
  <i>Note: Ensure Apache is running in your XAMPP Control Panel.</i>
</p>
